## 現在地(2026-07-02)

v0.1 の技術検証はほぼ完了。パイプライン3部品(A: ポーズ抽出 / B: 認識モデル / C: LLM整形)が
一通り結線され、撮影→取り込み→エクスポート→辞書化→評価のループから手作業が消えた。
「仕組みを作る」フェーズから「**データを増やして精度を測る**」フェーズへ移行した。

```
手話動画
  → 部品A: ポーズ抽出(pose_extractor、手ポーズ列 126次元)
  → 部品B: 認識モデル(transformer_burn、タグ + 確率の top-k)
  → 部品C: LLM 整形(llm_shaping、①プロンプト試作済み)
  → 日本語
```

### 短期の最重要リスク

pipe-v2 基準(top-1 70% / top-5 90%)と実測(ミラー拡張あり top-1 27-29% / top-5 51-65%)の
ギャップが大きいことが確定した(2026-08-14)。ミラー拡張の効果自体は一貫している(なし:
top-1 8-10%・top-5 20-24% → あり: 27-29%・51-65%)が、それだけでは基準に届かない。
学習には無視できない実行間の揺れも残る(seed固定後も wgpu の非決定性で top-1 27-29% 程度は動く)。
次のレバー((1) テイク数 3→5 (2) モデルスケールアップ (3) 語彙の類似動作整理 (4) ミラー拡張を
本番モデルへ反映)のうちどれを引くか、複数を組み合わせるかはユーザー判断待ち。
